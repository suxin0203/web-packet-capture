                抓包助手 - 操作手册（网页版）
═══════════════════════════════════════════════════════

【一分钟上手】

  1. 双击「抓包工具网页版.exe」
     · 若弹出「用户账户控制」(UAC) 窗口点「是」→ 管理员模式，证书静默安装
       全程无弹窗
     · 点「否」也没关系 → 普通模式，首次抓包时会弹一次证书确认框（已自动置顶）
     之后浏览器会自动打开操作页面
  2. 需要过滤就填顶部的框（不填 = 抓全部请求）：
       URL 包含    → 只抓网址里有这个关键字的请求
       Header 包含 → 只抓带某个请求头的请求（如 Cookie）
       内容包含    → 在请求体/响应体里搜关键字（token 常藏在这）
     注意：条件填了之后会自动记住，下次打开还在；
     如果列表一直没数据，先把条件清空试试！
  3. 点「▶ 开始抓包」→ 自动装证书、自动设置系统代理
  4. 去操作你的目标页面（小程序/手机/网页），请求会实时出现在列表里
  5. 点任意一条看详情（请求头/请求体/响应体，关键字黄色高亮，
     JSON 自动排版）；底部「提取结果」自动提取 token/cookie，点「复制」
  6. 用完点右上角红色「⏻ 退出程序」，网络自动恢复

【退出方式（都安全，不会断网）】

  · 点「■ 停止」         → 只停抓包，软件还开着，可改条件再抓
  · 点「⏻ 退出程序」     → 停抓包 + 恢复网络 + 软件退出
  · 关掉所有网页标签页   → 10 秒后软件自动退出并恢复网络
  · 关掉黑色控制台窗口 / Ctrl+C → 退出并恢复网络

  注意：运行时屏幕上那个黑色控制台窗口是抓包服务本身，
  抓包期间请不要关闭它；抓完用上面任意方式退出即可。

  万一还是打不开网页：双击「强制关闭代理-断网修复.bat」一键恢复。

【常用技巧】

  · 只抓某一个接口：URL 包含 填接口路径的关键字（如 progress）
  · 找登录凭证：先全部留空抓一轮，在列表里找 login / token 相关请求，
    再用 Header 包含 或 内容包含 精确过滤
  · 「提取结果」按 Header 关键字自动去重提取，点一下就复制
  · 「导出 JSON」可把本次所有记录存成文件
  · 搜索框可对列表二次过滤（路径/域名/关键字）

【常见问题】

  Q：点了开始抓包，列表一直没数据？
     1) 顶部过滤条件太严会把请求全滤掉 → 先清空 URL/Header/内容
        三个框，能抓到再逐个加回条件
     2) 确认右上角状态是「运行中」
     3) HTTPS 需要装证书：首次点「开始抓包」时 Windows 会弹一次证书确认框，
        点「是」即可（仅一次）；错过了就点顶部「证书」徽标补装

  Q：网页打不开 / 电脑没网了？
     1) 双击「强制关闭代理-断网修复.bat」
     2) 或手动：设置 → 网络和Internet → 代理 → 关闭"使用代理服务器"

  Q：手机抓包？
     1) 在网页上取消勾选「自动设置系统代理」
     2) 手机和电脑连同一 WiFi，手机 WiFi 设置里手动配代理：
        服务器填电脑IP，端口填界面显示的代理端口
     3) 点「开始抓包」即可，退出时网络设置不受影响

  Q：提示端口被占用？
     不用管，软件会自动换一个可用端口，以界面顶部显示的为准。

  Q：软件出问题了怎么反馈？
     把 logs 目录里的 service.log 发给作者即可，里面有完整的运行记录。

【注意事项】

  · 抓包数据包含 cookie、token 等敏感信息，导出文件注意保密
  · 软件只监听本机 (127.0.0.1)，局域网其他人连不上你的抓包服务
  · 首次运行 Windows Defender 可能扫描几秒；首次会弹一次证书确认框，
    已自动置顶到最前，点「是」即可
  · 如果公司电脑组策略限制了代理设置，界面顶部会提示，
    点「以管理员重启」按提示操作即可

【文件说明】

  抓包工具网页版.exe              主程序（双击运行）
  config.ini                      首次运行自动生成，界面上的设置都存在这里
                                   （一般不用手动编辑；高级用户可直接改）
  操作手册.txt                    本文件
  强制关闭代理-断网修复.bat        紧急恢复网络用
  logs/service.log                运行日志（排障用，滚动覆盖）
  logs/*.jsonl                    抓包记录（每行一条 JSON）
