================================================================================
                            抓包工具 - 常见问题排查
================================================================================

【问题1】网络无法访问 / 网页打不开
--------------------------------------------------------------------------------
症状：运行工具后，浏览器无法访问任何网站

原因：系统代理未正常关闭

解决方法：
  1. 右键管理员运行 "强制关闭代理-断网修复.bat"
  2. 或手动关闭：
     - 按 Win+I 打开设置
     - 进入 "网络和Internet" -> "代理"
     - 关闭 "使用代理服务器"


【问题2】HTTPS 网站显示证书警告 / 连接不是专用连接
--------------------------------------------------------------------------------
症状：访问 HTTPS 网站时浏览器显示安全警告

原因：证书未正确安装到受信任的根证书颁发机构

解决方法：
  方法一（推荐）：
    1. 重新运行工具（第二次运行会自动安装证书）
    2. 重启浏览器
  
  方法二（手动安装）：
    1. 浏览器访问 http://mitm.it
    2. 点击 "Windows" 下载证书
    3. 双击证书文件
    4. 选择 "安装证书"
    5. 存储位置选择 "当前用户"
    6. 证书存储选择 "受信任的根证书颁发机构"
    7. 完成安装后重启浏览器
  
  方法三（验证证书）：
    1. 按 Win+R，输入 certmgr.msc
    2. 展开 "受信任的根证书颁发机构" -> "证书"
    3. 查找 "mitmproxy" 证书
    4. 如果没有，使用方法二手动安装


【问题3】抓不到数据 / 没有捕获到请求
--------------------------------------------------------------------------------
症状：工具运行正常，但没有显示任何请求

可能原因及解决方法：

  原因1：目标URL配置错误
    - 检查 config.ini 中的 TARGET_URL 是否正确
    - 确保 TARGET_URL 是 URL 的一部分（不需要完整URL）
    - 例如：TARGET_URL=api/user 可以匹配 https://example.com/api/user/login
  
  原因2：浏览器未使用系统代理
    - Chrome/Edge：默认使用系统代理，无需配置
    - Firefox：需要手动配置代理
      设置 -> 网络设置 -> 手动代理配置
      HTTP代理：127.0.0.1  端口：8080
      勾选 "也将此代理用于 HTTPS"
  
  原因3：应用程序不走系统代理
    - 某些应用（如微信小程序、独立APP）可能不使用系统代理
    - 需要在应用内单独配置代理
  
  原因4：证书未安装
    - 参考【问题2】安装证书


【问题4】工具启动失败 / 闪退
--------------------------------------------------------------------------------
症状：双击运行后窗口立即关闭

可能原因及解决方法：

  原因1：未以管理员身份运行
    - 右键点击 "抓包工具.exe"
    - 选择 "以管理员身份运行"
  
  原因2：端口被占用
    - 检查 8080 端口是否被其他程序占用
    - 按 Win+R，输入 cmd
    - 执行：netstat -ano | findstr :8080
    - 如果端口被占用，修改 config.ini 中的 PROXY_PORT
  
  原因3：缺少依赖（仅限 Python 脚本模式）
    - 运行：pip install -r requirements.txt


【问题5】日志文件找不到 / logs 目录为空
--------------------------------------------------------------------------------
症状：工具运行后找不到日志文件

解决方法：
  1. 日志保存在 exe 所在目录的 logs 文件夹
  2. 确认是否真的捕获到了请求（参考【问题3】）
  3. 检查是否有权限写入文件
     - 右键 exe 所在文件夹 -> 属性 -> 安全
     - 确保当前用户有 "写入" 权限


【问题6】杀毒软件报毒 / 被拦截
--------------------------------------------------------------------------------
症状：运行时被杀毒软件拦截或删除

原因：PyInstaller 打包的 exe 可能被误报

解决方法：
  1. 将 exe 添加到杀毒软件白名单
  2. 或临时关闭杀毒软件（不推荐）
  3. 或使用 Python 脚本模式运行（不打包）


【问题7】Ctrl+C 退出后显示英文提示
--------------------------------------------------------------------------------
症状：按 Ctrl+C 后显示 "Terminate batch job (Y/N)?"

原因：这是 Windows 系统的标准提示，不是程序错误

解决方法：
  - 输入 Y 或直接按回车即可完全退出
  - 这是正常现象，不影响使用


【问题8】配置文件修改后不生效
--------------------------------------------------------------------------------
症状：修改 config.ini 后，工具仍使用旧配置

解决方法：
  1. 确保保存了 config.ini 文件
  2. 重新启动工具（关闭后重新运行）
  3. 检查 config.ini 格式是否正确：
     [Settings]
     TARGET_URL=你的目标URL
     PROXY_PORT=8080
     LOG_DIR=logs


【问题9】抓包数据不完整 / 响应体为空
--------------------------------------------------------------------------------
症状：捕获到请求，但响应体显示为空或不完整

可能原因：
  1. 响应是二进制数据（图片、文件等）
     - 日志会显示 "<binary data: xxx bytes>"
     - 这是正常的，二进制数据不会完整显示
  
  2. 响应被压缩（gzip、br等）
     - mitmproxy 会自动解压，如果仍为空可能是解压失败
  
  3. 响应体过大被截断
     - 查看日志文件中的完整内容
     - 或修改抓包脚本.py 中的截断长度限制


【问题10】程序运行缓慢 / 卡顿
--------------------------------------------------------------------------------
症状：工具运行时电脑变慢或程序响应慢

可能原因及解决方法：

  原因1：捕获了大量请求
    - 设置更精确的 TARGET_URL 过滤
    - 定期清理 logs 目录的旧文件
  
  原因2：日志文件过大
    - 单个日志文件过大会影响性能
    - 建议定期重启工具生成新的日志文件


【问题11】无法捕获移动端/模拟器的请求
--------------------------------------------------------------------------------
症状：想抓取手机或模拟器的请求，但抓不到

解决方法：
  1. 确保手机/模拟器与电脑在同一网络
  2. 在手机/模拟器上配置代理：
     - 代理地址：电脑的 IP 地址（不是 127.0.0.1）
     - 代理端口：8080（或 config.ini 中配置的端口）
  3. 在手机/模拟器上安装证书：
     - 浏览器访问 http://mitm.it
     - 下载并安装证书
  4. 修改 main.py 中的代理监听地址（高级）：
     - 将 127.0.0.1 改为 0.0.0.0 以监听所有网络接口


【问题12】特定网站抓不到（如微信、QQ等）
--------------------------------------------------------------------------------
症状：大部分网站都能抓到，但某些特定应用抓不到

原因：某些应用使用了证书锁定（Certificate Pinning）

解决方法：
  - 这是应用的安全机制，无法通过简单配置绕过
  - 需要使用更高级的工具（如 Frida）进行 Hook
  - 或使用应用的测试版/开发版（通常没有证书锁定）

================================================================================
                                快速命令参考
================================================================================

查看端口占用：
  netstat -ano | findstr :8080

查看系统代理状态：
  reg query "HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings" /v ProxyEnable

手动关闭系统代理：
  reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings" /v ProxyEnable /t REG_DWORD /d 0 /f

查看证书：
  certmgr.msc

查看本机IP地址：
  ipconfig
