📖 三步上手

第一次用？跟着下面走就行
1点「▶ 开始抓包」——首次会弹 Windows 证书确认框，点「是」（仅一次）需要过滤就填上方的框：URL 包含 / Header 包含 / 内容包含，不填 = 抓全部，随时可改
2去操作你的目标页面（小程序 / 手机 / 网页），请求会实时出现在左侧列表点任意一条看详情；关键字黄色高亮；底部「提取结果」一键复制 token/cookie
3用完点右上角「⏻ 退出程序」，网络自动恢复黑色控制台窗口是抓包服务，抓包期间不要关它
💡 小提示：断网点「修复网络」；抓包数据在 logs 目录；出问题把 logs/service.log 发给作者
以后可随时点右上角「📖 使用指南」再次查看
